# 📚 Знаток Онлайн

Викторина в формате «Что? Где? Когда?» для платформы SmartApp (Сбер). Отвечайте на вопросы текстом или голосом через ассистента Салют.

![Скриншот игры](https://mikhvl.github.io/znatok-online/screenshot.png)

## Возможности

- 🎤 **Голосовое управление** — говорите «Начать игру», «Ответ …», «Проверить», «Дальше», «Закончить»
- 📺 **Адаптивный интерфейс** — работает на телефонах, планшетах, компьютерах и телевизорах (SberBox, SberTV)
- 🎮 **Навигация с пульта** — поддержка кнопок «Вперёд» и «Назад»
- 🔀 **Случайные вопросы** — каждый раз новый набор из 5 вопросов
- 🔊 **Озвучка вопросов и ответов** через ассистента

## Локальный запуск

### Переменные окружения

Создайте файл `.env` в корне проекта:

```env
REACT_APP_SMARTAPP="Знаток Онлайн - Викторина"
REACT_APP_TOKEN=<ваш_токен_из_SaluteStudio>
```

Токен можно получить в [SaluteStudio](https://salute.sber.ru/) в настройках проекта.

### Сборка и запуск

```bash
# Установка зависимостей
yarn install

# Создайте файл .env с токеном для ассистента (см. ниже)
# Запуск dev-сервера
yarn start
```

## Деплой на GitHub Pages

```bash
yarn deploy
```
